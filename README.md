# NEW ERA Renewal

## 1. 프로젝트 소개

뉴에라(NEW ERA)의 브랜드 콘텐츠와 상품 컬렉션을 소개하는 React 기반 웹 프런트엔드 프로젝트입니다. 브랜드 히스토리, 모자 실루엣, 협업 컬렉션, 룩북을 하나의 메인 페이지에 구성하고, 카테고리별 상품 탐색과 장바구니·좋아요 화면을 연결했습니다.

스크롤에 따라 폴라로이드 카드가 펼쳐지고 텍스트 마스크가 확대되는 인터랙션을 구현했습니다. 상품 정보는 `src/data/`의 로컬 JSON을 사용합니다.

## 2. 기획 의도 및 목표

- 기획 배경: 기존 뉴에라 공식 웹사이트는 상품 탐색과 판매 중심으로 구성되어 있어, 브랜드가 가진 100년 이상의 헤리티지와 고유한 아이덴티티를 전달하는 데 아쉬움이 있다고 판단했습니다.

- 개선 방향 및 목표: 브랜드의 역사와 정체성을 강조하고, 스크롤 기반 인터랙션과 시각적 콘텐츠를 활용해 브랜드 경험을 강화하고자 했습니다. 또한 브랜드 스토리에서 제품 탐색으로 자연스럽게 이어지는 사용자 경험을 목표로 리뉴얼을 진행했습니다.


## 3. 사용 기술 및 라이브러리

버전은 `package.json`의 선언을 기준으로 작성했습니다.

| 기술 | 버전 | 사용 내용 |
| --- | --- | --- |

## 4. 주요 기능 및 인터랙션

### 브랜드 메인 페이지

- **Hero 폴라로이드:** 9장의 카드를 스크롤 진행에 따라 겹친 상태에서 3×3 배열로 펼칩니다. GSAP의 `pin`과 `scrub`을 사용하며 역스크롤 시 같은 타임라인을 되감습니다.
- **FOR YOU 전환:** SVG 텍스트 마스크를 확대하고 투명도를 변경해 다음 카테고리 영역을 드러냅니다.
- **브랜드 히스토리:** 1920년대부터 2020년대까지의 카드를 Swiper로 탐색합니다. 이전·다음 버튼, 페이지 표시 버튼, 키보드 조작과 카드의 hover·포커스 상세 설명을 제공합니다.
- **AUTHENTIC 모션:** 스크롤에 따라 원형 요소의 크기·위치·회전·색상을 변경합니다.
- **실루엣·협업 컬렉션:** 모자 유형과 협업 브랜드별 카테고리 페이지로 연결합니다.
- **SHOP ALL 룩북:** sticky 카드가 스크롤에 따라 겹치며 회전합니다. 데스크톱에서는 전신 이미지가 2배에서 원래 크기로 축소되며, CSS 뷰 타임라인 미지원 환경에는 GSAP 회전 처리를 제공합니다.

### 상품 탐색 및 쇼핑 상태

- **카테고리 목록:** FW26, 모자, 의류, 액세서리, 키즈, BlackLabel 및 실루엣·협업 컬렉션 등 18개 카테고리의 로컬 상품 데이터를 표시합니다.
- **필터·정렬:** 상품 종류별 필터, 상품 수 표시, 기본순·낮은 가격순·높은 가격순 정렬을 지원합니다. 헤더 하위 메뉴의 `filter` 쿼리로 초기 필터를 지정합니다.
- **상품 상세 화면:** FW26 상품 ID에 해당하는 `#/product/{id}` 경로에서 이미지, 상품명, 가격, 상품 코드와 분류를 표시합니다.
- **카테고리 검색:** 주요 6개 카테고리의 이름과 지정 키워드를 검색하고 추천 검색어를 선택할 수 있습니다.
- **장바구니:** 상품 추가, 동일 상품 수량 누적, 수량 변경(1~99개), 삭제 및 상품 합계를 제공합니다.
- **좋아요:** 상품별 선택·취소와 별도 목록을 제공합니다. 장바구니와 좋아요는 새로고침 후에도 유지되며, 같은 출처의 탭 간 저장소 변경을 반영합니다.

### 화면 이동 및 사용성

- `usePageNavigation`에서 해시 경로를 처리하고 브라우저 방문 기록별 스크롤 위치를 저장·복원합니다.
- 화면별 문서 제목, 본문 바로가기, 입력 레이블, 버튼의 접근성 속성과 상태 안내를 제공합니다.
- CSS 미디어 쿼리로 화면 너비에 따라 레이아웃을 조정하고 맨 위로 이동 버튼을 제공합니다.

### 현재 구현 범위

- 로그인 화면은 입력 폼과 **페이지 내부에서만 유지되는 테스트용 로그인**을 제공합니다. 인증 서버는 연결되어 있지 않습니다.
- 회원가입은 입력 폼과 안내 메시지까지 구현되어 있으며, 회원 정보 저장 및 카카오 인증은 연결되어 있지 않습니다.
- 검색 대상은 주요 카테고리이며 상품명 전체 검색은 구현되어 있지 않습니다.
- 상품 상세 경로는 현재 FW26 데이터에 한정되어 있습니다.
- 장바구니는 브라우저 저장소 기반이며 주문·결제 기능은 구현되어 있지 않습니다.

## 6. 설치 및 실행 방법

### 준비 환경

- Node.js 22 및 npm: 저장소의 GitHub Actions에서 사용하는 Node.js 버전입니다.
- 아래 명령은 `package.json`이 있는 `newera-renewal` 폴더에서 실행합니다.

### 의존성 설치 및 개발 서버 실행

```bash
npm ci
npm run dev
```

개발 서버의 기본 접속 주소는 `http://127.0.0.1:5173/newear/`입니다. 포트가 사용 중이면 터미널에 표시된 주소를 확인하세요. `/newear/`는 `vite.config.js`에 지정된 기본 경로입니다.

Windows PowerShell에서 npm 스크립트 실행이 제한되는 경우 `npm` 대신 `npm.cmd`를 사용할 수 있습니다.

### 코드 검사 및 프로덕션 빌드

```bash
npm run lint
npm run build
```

빌드 결과는 `dist/`에 생성됩니다. 빌드 결과를 로컬에서 확인하려면 다음 명령을 실행한 뒤 터미널에 표시된 주소의 `/newear/` 경로로 접속합니다.

```bash
npm run preview
```

## 7. 배포 사이트 링크

- 배포 설정 기준 주소: [NEW ERA Renewal](https://hagyomi.github.io/newear/)

위 주소는 Git 원격 저장소 `hagyomi/newear`와 Vite의 기본 경로 `/newear/`, GitHub Pages 배포 워크플로를 기준으로 작성했습니다. 실제 배포 성공 여부와 사이트 접속 상태는 별도 확인이 필요합니다.

배포 워크플로는 `main` 브랜치에 push하거나 수동 실행하면 Node.js 22에서 `npm ci` → `npm run lint` → `npm run build -- --base=/newear/`를 수행하고 `dist/`를 GitHub Pages에 배포하도록 구성되어 있습니다.
